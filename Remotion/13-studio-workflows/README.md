# 13 - Studio workflows

This section covers day-to-day Remotion authoring workflows: Studio, styling, editor starter kits, timeline/recorder concepts, AI-assisted video generation, brownfield installation, and security/license considerations.

## Learning goals

- Use Remotion Studio as a controlled authoring and review environment.
- Integrate Tailwind or CSS systems without losing render determinism.
- Understand Remotion editor starter, timeline, and recorder building blocks.
- Use AI tools and agents responsibly around Remotion projects.
- Add Remotion to an existing React app without disrupting the host app.
- Explain license, security, and trusted-code boundaries.
