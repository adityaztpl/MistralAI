# Flashcards and 60-Second Drills

This section turns the curriculum into active recall practice. The goal is not to reread notes; it is to make interview answers available under pressure.

## How to use spaced repetition

Use this rhythm:

1. **Day 0**: Try every card once. Mark each card `easy`, `medium`, or `hard`.
2. **Day 1**: Repeat only `medium` and `hard` cards.
3. **Day 3**: Repeat all cards you missed or answered slowly.
4. **Day 7**: Shuffle across topics.
5. **Day 14**: Answer out loud with no notes.
6. **Interview week**: Do 20 mixed cards daily plus 3 verbal drills.

## How to answer each card

Use this structure:

```text
Definition -> Why it matters -> Example -> Trade-off or failure mode
```

For architecture questions, use:

```text
Requirement -> Design choice -> Risk -> Validation metric
```

## Practice modes

### Fast recall

- Read the question.
- Answer in 20 seconds.
- Reveal the answer.
- Rewrite missed answer in one sentence.

### Interview mode

- Answer in 60-90 seconds.
- Include one production concern.
- Include one trade-off.
- End with a validation metric.

### Deep mode

- Turn one card into a whiteboard discussion.
- Draw data flow.
- Identify failure modes.
- Propose tests and metrics.
